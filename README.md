## 🌟 О проекте

**ZiablWinSetup** — это комплексный, автономный и быстрый инструмент для настройки, обслуживания и автоматической подготовки рабочей среды Windows после чистой переустановки ОС или покупки нового ПК/ноутбука.

Забудьте о ручном скачивании десятков инсталляторов из браузера, назойливой рекламе и кликах «Далее-Далее-Готово»: выберите нужный софт галочками или пресетом, примените проверенные системные твики, удалите лишний bloatware и нажмите **«Скачать выбранное»**!

### 🚀 4. Менеджер автозагрузки с анализом нагрузки

<p align="center">
  <img src="assets/screenshots/03_startup_manager.png" alt="Менеджер автозагрузки" width="920" />
</p>

Полноценный диагностический центр автозапуска, превосходящий стандартный Диспетчер задач:
- 📊 **Оценка влияния на запуск (Impact)**:
  - 🔴 **Высокое** — ресурсоёмкие клиенты, фоновые лаунчеры и тяжелые службы.
  - 🟡 **Среднее** — сервисы синхронизации и утилиты периферии.
  - 🟢 **Низкое** — легковесные службы, фоновые трей-агенты.
  - ⚪ **Не замерено** — недавно добавленные элементы.
- 🔍 **Глубокий охват всех системных источников**:
  - Пользовательский и системный реестр: `HKCU\Run`, `HKLM\Run`, `HKLM\RunOnce`, `WOW6432Node`.
  - Системные службы Windows (`services.msc`).
  - Планировщик задач Windows (`Task Scheduler`).
  - Папки автозагрузки (`Startup` в `%APPDATA%` и `%PROGRAMDATA%`).
  - UWP/Metro приложения с автозапуском.
- 🛡️ **Безопасное включение и отключение**: использование официального Windows-механизма `StartupApproved`, предотвращающего безвозвратное удаление путей к исполняемым файлам.
- 📂 **Быстрый переход к файлу**: открытие расположения программы в Проводнике (`explorer.exe /select`) в 1 клик.

### 📥 5. Менеджер загрузок (Downloads Manager) со скоростью и ETA

- ⚡ **Реальная скорость и объём данных**: непрерывный подсчёт скорости передачи (`МБ/с` или `КБ/с`), переданных мегабайт и расчёт оставшегося времени (`ост. XXс`), в том числе для Winget и прямых сетевых загрузок.
- 🛑 **Мгновенная отмена**: надёжное прерывание активных сетевых сокетов и фоновых подпроцессов без зависаний программы и без мусора на диске.
- 📊 **Отдельная вкладка «Загрузки»**: удобная сводная панель активных, завершённых и прерванных загрузок с живым бейджем-счётчиком в навигационной панели.
- 📂 **Быстрый переход**: открытие папки загрузок или конкретного скачанного установщика в Проводнике Windows в 1 клик.
- 🧹 **Очистка истории и кэша**: безопасное удаление временных файлов `.part`, `.tmp` и старых дистрибутивов.

## 🚀 Как запустить

### Вариант 1. Готовый исполняемый файл (Рекомендуется)

Не требует установки Python и каких-либо сторонних компонентов:

👉 **[Скачать актуальный ZiablWinSetup.exe](https://github.com/DanielCarti/ZiablWinSetup/releases/latest)**

1. Скачайте файл `ZiablWinSetup.exe`.
2. Запустите его (для полного доступа ко всем твикам и реестру рекомендуется запуск от имени администратора).

---

### Вариант 2. Запуск из исходного кода

```bash
# Клонируйте репозиторий
git clone https://github.com/DanielCarti/ZiablWinSetup.git
cd ZiablWinSetup

# Установите зависимости
pip install -r requirements.txt

# Запустите проект
python main.py
```
Либо дважды кликните по файлу `run.bat`.

---

## 🛠️ Сборка собственного EXE

Для компиляции автономного исполняемого файла используется **PyInstaller**:

```bash
pyinstaller --clean ZiablWinSetup.spec
```
Или запустите готовый командный файл:
```cmd
build.bat
```
Собранный `.exe` будет находиться в папке `dist/ZiablWinSetup.exe`.
