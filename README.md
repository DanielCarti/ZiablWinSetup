## 🌟 О проекте

**ZiablWinSetup** — это легковесный, автономный и быстрый инструмент для автоматической подготовки и оптимизации системы после чистой установки Windows или покупки нового ПК.

Больше не нужно вручную открывать десятки сайтов, закрывать рекламные баннеры и кликать «Далее-Далее-Готово»: выберите нужные программы галочками, настройте системные твики и нажмите **«Скачать выбранное»**!

## ✨ Ключевые возможности

### 🎨 Интерфейс Windows 11 Fluent Design
- **Стильный и чистый интерфейс**: эффект Mica/Acrylic, утончённые карточки с динамическими эффектами наведения, современная шрифтовая гарнитура *Segoe UI Variable*.
- **Новый визуальный стиль и брендинг**: футуристичный логотип внутри приложения и минималистичная плоская иконка исполняемого файла.
- **Поддержка HiDPI и плавный рендеринг**: мгновенная отрисовка каталога (0 мс) без мерцания и подвисаний.
- **Мгновенное переключение языка (RU / EN)**: переводит на лету названия, категории, описания программ и системные твики.

### 🔄 Интеллектуальный центр обновлений
- **Автоматическая проверка обновлений**: поиск свежих версий через Winget и GitHub Releases API.
- **Редизайн кнопки «Обновить»**: выразительная Windows 11 кнопка с подсветкой и акцентным градиентом на карточках программ с доступной новой версией.
- **Исключения из автообновления**: диалоговое окно настройки программ-исключений (например, для специализированных версий ПО).
- **Кнопка повторного сканирования**: мгновенно синхронизирует статус установленных программ в системе без перезапуска.

### ⚡ Системные твики и оптимизация (Вкладка «Твики и фичи»)
- 🚀 **Максимальная производительность**: разблокировка и активация скрытой схемы питания Windows *Ultimate Performance* с минимальными задержками CPU.
- 📁 **Показ расширений файлов**: включение отображения расширений всех типов файлов в Проводнике.
- 📋 **Классическое контекстное меню**: возврат полного контекстного меню Windows 10 в Windows 11 без пункта «Показать дополнительные параметры».
- 🚫 **Блокировка рекламы в торрент-клиентах**: полное удаление и двустороннее переключение рекламных баннеров и всплывающих окон в BitTorrent и uTorrent через безопасное управление `settings.dat`.
- 💾 **Отключение индексации поиска для SSD**: остановка и отключение службы `WSearch` (Windows Search) для продления ресурса записи накопителей (TBW) и снижения фоновой нагрузки.
- 🔍 **Скрытие поиска на Панели задач**: отключение громоздкого поискового поля на панели задач для освобождения рабочего места.
- 📌 **Выравнивание Панели задач по левому краю**: возврат привычного классического расположения кнопки «Пуск» и значков слева в Windows 11.
- 🧹 **Очистка кэша Steam**: устранение зависаний обновлений игр, очистка шейдеров и кэша встроенного браузера.
- 💬 **Очистка медиа-кэша Telegram**: освобождение гигабайтов дискового пространства без удаления облачных переписок.
- 🔇 **Отключение рекламы в Пуске**: выключение подсказок, рекламы приложений и промо-блоков в меню «Пуск» Windows 10/11.

### 🪟 Встроенные Metro / UWP приложения (Вкладка «Metro приложения»)
- **Полный контроль над предустановленным софтом**: отдельный экран с 21 встроенным UWP-приложением Windows (Погода MSN, Новости, Кортана, Связь с телефоном, Камера, Карты, Xbox Game Bar, Запись голоса, Советы, Solitaire, Paint 3D, Clipchamp и др.).
- **Удаление в 1 клик**: чистое удаление ненужного встроенного ПО через PowerShell AppX API без прав администратора.
- **Восстановление в 1 клик**: повторная регистрация манифеста из хранилища Windows, установка через Winget MSStore или прямой переход в Microsoft Store.
- **Массовые операции**: выбор нескольких приложений и пакетное удаление или восстановление.

### 🛡️ Надёжность и безопасность
- **Защита от закрытия**: встроенное предупреждение Windows перед закрытием программы, если в данный момент идёт скачивание или установка.
- **Умная обработка ZIP и портативных утилит**: автоматическая распаковка и создание готовых ярлыков на Рабочем столе текущего пользователя (Zapret и др.).
- **Поддержка прав Администратора**: автоматический запуск или перезапуск инсталляторов с повышенными привилегиями при необходимости.

## 🚀 Как запустить

### Вариант 1. Автономный EXE (без установки Python)
Готовый исполняемый файл находится в папке:
```
dist\ZiablWinSetup.exe
```
Просто скопируйте его на флешку и запускайте на любом ПК под управлением **Windows 10 / 11 (x64)**.

### Вариант 2. Запуск из исходного кода
```bash
# Клонируйте репозиторий
git clone https://github.com/<username>/ZiablWinSetup.git
cd ZiablWinSetup

# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python main.py
```
Или запустите файл `run.bat` двойным кликом.

## 🛠️ Сборка собственного EXE

Для сборки одного независимого `.exe` файла используется **PyInstaller**:
```bash
pyinstaller --clean ZiablWinSetup.spec
```
Или запустите готовый скрипт:
```cmd
build.bat
```
Результат сборки появится в папке `dist/ZiablWinSetup.exe`.
